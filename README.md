# Mokoko güncellemeleri

Mokoko (Mi Box için film/dizi uygulaması) yeni sürümleri buraya konur.
Uygulama açılışta `latest.json` dosyasına bakar; daha yeni bir sürüm varsa
"Yeni sürüm var" diye sorar ve `Mokoko.apk` dosyasını indirip kurar.

- `latest.json` — son sürümün numarası, adı ve notları
- `Mokoko.apk` — son sürümün kurulum dosyası
